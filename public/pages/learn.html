LESSON 1 OF 13

WHAT IS PHP?

PHP is a server-side programming language. The web server runs your PHP code and sends only the result (usually HTML) to the browser. Visitors never see your PHP source.

How a PHP page works

  • The browser asks the server for page.php.
  • The server runs the PHP code inside the file.
  • Whatever the code outputs (with echo) is sent back to the browser as HTML.

Your first script

PHP code goes between <?php and ?>. Every statement ends with a semicolon.

echo "Hello, World!";
OUTPUT
Hello, World!

Mixing PHP and HTML

A .php file can contain normal HTML. Only the parts inside PHP tags are run. <?= ... ?> is a short way to write <?php echo ... ?>.

<h1>Welcome</h1>
<p>Today is <?= date("l") ?>.</p>
<?php if (date("H") < 12): ?>
    <p>Good morning!</p>
<?php endif; ?>

Output and comments

// A single-line comment
# Also a single-line comment
/* A comment that
   spans several lines */
echo "A", "B";   // echo can print several values
print "C";       // print prints one value
echo "\n";
var_dump(42);    // shows the type and the value
OUTPUT
ABC
int(42)
TIP: Use var_dump() while debugging: it shows both the type and the value, so you can tell "5" (string) from 5 (int).
COMMON MISTAKE: A file that contains only PHP should leave out the closing ?>. Any blank line after it would be sent to the browser by accident.

REMEMBER

  • PHP runs on the server; the browser only receives the output.
  • Code goes inside <?php ... ?> and statements end with ;.
  • echo / print output text; var_dump() is for debugging.

VARIABLES & DATA TYPES

A variable stores a value so you can use it later. In PHP every variable name starts with $, and you do not declare a type: PHP works it out from the value.

Creating variables

$name = "Ana";      // string
$age = 20;          // int
$height = 1.65;     // float
$isStudent = true;  // bool
$nothing = null;    // null

echo "$name is $age years old.";
OUTPUT
Ana is 20 years old.
  • Names start with a letter or underscore after the $: $user_name is valid, $2user is not.
  • Names are case-sensitive: $Age and $age are different variables.

The data types

var_dump("hi", 7, 3.5, false, null, [1, 2]);
OUTPUT
string(2) "hi"
int(7)
float(3.5)
bool(false)
NULL
array(2) {
  [0]=>
  int(1)
  [1]=>
  int(2)
}

Check a type with gettype() or with the is_* functions: is_int(), is_string(), is_array(), is_null() and so on.

Type juggling and casting

PHP converts types automatically when it needs to. You can also convert explicitly with a cast.

echo "10" + 5, "\n";        // 15: the string becomes a number
echo (int) "42abc", "\n";   // 42
echo (string) 3.0, "\n";    // 3
var_dump((bool) "0");       // false
OUTPUT
15
42
3
bool(false)

These values are treated as false: false, 0, 0.0, "", "0", [] and null. Everything else is true.

isset() and empty()

$a = 0;
$b = null;
var_dump(isset($a), isset($b), empty($a));
OUTPUT
bool(true)
bool(false)
bool(true)

Constants

A constant holds a value that never changes. It has no $ and is usually written in capitals.

define("SITE_NAME", "CodeMaster");
const MAX_HP = 100;
echo SITE_NAME, " ", MAX_HP;
OUTPUT
CodeMaster 100
COMMON MISTAKE: Using a variable that was never set gives an "Undefined variable" warning. Check it with isset() or give a default with ??.

REMEMBER

  • Variables start with $; constants do not.
  • Types: string, int, float, bool, array, object, null.
  • "0", "", 0, [] and null are all false.
LESSON 3 OF 13

OPERATORS

Operators do work on values: arithmetic, comparing, combining conditions and joining strings.

Arithmetic

echo 7 + 2, " ", 7 - 2, " ", 7 * 2, " ", 7 / 2, " ", 7 % 2, " ", 2 ** 3;
OUTPUT
9 5 14 3.5 1 8

% is the remainder (modulo) and ** is the power. intdiv(7, 2) gives the whole-number result 3.

Assignment shortcuts

$hp = 50;
$hp += 10;   // 60
$hp -= 5;    // 55
$hp *= 2;    // 110
$name = "Code";
$name .= "Master";
echo $hp, " ", $name;
OUTPUT
110 CodeMaster

Increment and decrement

$i = 5;
echo $i++, " ";  // prints 5, then $i becomes 6
echo ++$i;       // $i becomes 7, then prints 7
OUTPUT
5 7

Comparison: == vs ===

== compares values after converting types. === also requires the same type. Prefer ===.

var_dump(5 == "5", 5 === "5", 5 != 6, 5 <=> 9);
OUTPUT
bool(true)
bool(false)
bool(true)
int(-1)

The spaceship operator <=> returns -1, 0 or 1. It is handy for sorting.

Logical operators

$hasKey = true;
$isBoss = false;
var_dump($hasKey && !$isBoss, $hasKey || $isBoss);
OUTPUT
bool(true)
bool(true)

Ternary and null coalescing

$score = 75;
echo $score >= 50 ? "Pass" : "Fail", "\n";
$data = [];
echo $data["name"] ?? "Guest";   // default when the key is missing or null
OUTPUT
Pass
Guest
COMMON MISTAKE: = assigns, == compares. Writing if ($x = 5) sets $x to 5 and is always true.

REMEMBER

  • % = remainder, ** = power, . = join strings.
  • Use === unless you really want type conversion.
  • ?? gives a default for missing or null values.

STRINGS

Strings are text. PHP has many built-in functions for working with them.

Single vs double quotes

$hero = "Knight";
echo "Hello $hero\n";      // variables and \n are expanded
echo 'Hello $hero\n';      // printed exactly as written
echo "\n";
echo "Level {$hero}s";     // braces mark where the variable ends
OUTPUT
Hello Knight
Hello $hero\n
Level Knights

Joining strings

$first = "Code";
$last = "Master";
echo $first . " " . $last;
OUTPUT
Code Master

Common string functions

$s = "Hello World";
echo strlen($s), "\n";               // 11
echo strtoupper($s), "\n";
echo strtolower($s), "\n";
echo ucfirst("php"), "\n";            // Php
echo substr($s, 0, 5), "\n";         // Hello
echo strpos($s, "World"), "\n";      // 6
echo str_replace("World", "PHP", $s), "\n";
echo trim("  spaced  "), "|";
OUTPUT
11
HELLO WORLD
hello world
Php
Hello
6
Hello PHP
spaced|

Splitting and joining

$parts = explode(",", "red,green,blue");
echo count($parts), "\n";
echo implode(" | ", $parts);
OUTPUT
3
red | green | blue

Formatting

printf("%s has %d HP (%.1f%%)\n", "Mage", 45, 45 / 60 * 100);
echo number_format(1234567.891, 2), "\n";
echo str_pad("7", 3, "0", STR_PAD_LEFT);
OUTPUT
Mage has 45 HP (75.0%)
1,234,567.89
007

PHP 8 helpers

var_dump(str_contains("dungeon", "geo"));
var_dump(str_starts_with("dungeon", "dun"));
var_dump(str_ends_with("dungeon", "on"));
OUTPUT
bool(true)
bool(true)
bool(true)
COMMON MISTAKE: strpos() returns 0 when the text is at the start, and 0 is falsy. Always compare with !== false, or use str_contains().

REMEMBER

  • Double quotes expand variables; single quotes do not.
  • String positions start at 0.
  • explode() splits a string into an array; implode() joins an array into a string.

ARRAYS

An array holds many values in one variable. PHP arrays can use numbers (indexed) or names (associative) as keys.

Indexed arrays

$items = ["Sword", "Shield", "Potion"];
echo $items[0], "\n";      // first item
$items[] = "Map";          // add to the end
echo count($items);
OUTPUT
Sword
4

Associative arrays

$hero = ["name" => "Ana", "hp" => 100, "class" => "Mage"];
echo $hero["name"], "\n";
$hero["hp"] -= 20;
foreach ($hero as $key => $value) {
    echo "$key: $value\n";
}
OUTPUT
Ana
name: Ana
hp: 80
class: Mage

Multidimensional arrays

$party = [
    ["name" => "Ana", "hp" => 80],
    ["name" => "Ben", "hp" => 65],
];
echo $party[1]["name"];
OUTPUT
Ben

Adding, removing and searching

$q = [2, 3];
array_push($q, 4);      // end
array_unshift($q, 1);   // start
$last = array_pop($q);  // removes 4
echo implode(",", $q), " | ", $last, "\n";
var_dump(in_array(3, $q), array_search(3, $q), array_key_exists(0, $q));
OUTPUT
1,2,3 | 4
bool(true)
int(2)
bool(true)

Sorting

$n = [5, 2, 9];
sort($n);   echo implode(",", $n), "\n";   // low to high
rsort($n);  echo implode(",", $n), "\n";   // high to low
$ages = ["Ana" => 30, "Ben" => 20];
asort($ages);  echo implode(",", array_keys($ages)), "\n";  // by value
ksort($ages);  echo implode(",", array_keys($ages));          // by key
OUTPUT
2,5,9
9,5,2
Ben,Ana
Ana,Ben

Transforming arrays

$nums = [1, 2, 3, 4, 5];
$doubled = array_map(fn($n) => $n * 2, $nums);
$evens = array_filter($nums, fn($n) => $n % 2 === 0);
$total = array_reduce($nums, fn($sum, $n) => $sum + $n, 0);
echo implode(",", $doubled), " | ", implode(",", $evens), " | ", $total;
OUTPUT
2,4,6,8,10 | 2,4 | 15

Merging and destructuring

$a = ["x" => 1];
$b = ["y" => 2];
print_r(array_merge($a, $b));
[$first, $second] = ["gold", "silver"];
echo $second;
OUTPUT
Array
(
    [x] => 1
    [y] => 2
)
silver
TIP: print_r() is the easiest way to look inside an array while debugging.

REMEMBER

  • Indexes start at 0; $arr[] = x appends.
  • Use foreach ($arr as $key => $value) to loop through any array.
  • array_map transforms, array_filter keeps some, array_reduce combines.

CONTROL FLOW

Control structures decide which code runs and how many times.

if / elseif / else

$score = 82;
if ($score >= 90) {
    echo "A";
} elseif ($score >= 80) {
    echo "B";
} else {
    echo "C";
}
OUTPUT
B

switch

$day = "Sat";
switch ($day) {
    case "Sat":
    case "Sun":
        echo "Weekend";
        break;
    default:
        echo "Weekday";
}
OUTPUT
Weekend
COMMON MISTAKE: Forgetting break in a switch makes PHP "fall through" and run the next case too.

match (PHP 8)

match is a stricter switch: it uses ===, returns a value and needs no break.

$code = 404;
echo match ($code) {
    200 => "OK",
    301, 302 => "Redirect",
    404 => "Not Found",
    default => "Unknown",
};
OUTPUT
Not Found

Loops

for ($i = 1; $i <= 3; $i++) {
    echo "for $i\n";
}
$hp = 3;
while ($hp > 0) {
    echo "while $hp\n";
    $hp--;
}
do {
    echo "do runs at least once\n";
} while (false);
foreach (["a", "b"] as $i => $letter) {
    echo "foreach $i=$letter\n";
}
OUTPUT
for 1
for 2
for 3
while 3
while 2
while 1
do runs at least once
foreach 0=a
foreach 1=b

break and continue

for ($i = 1; $i <= 10; $i++) {
    if ($i % 2 === 0) continue;  // skip even numbers
    if ($i > 7) break;           // stop the loop
    echo $i, " ";
}
OUTPUT
1 3 5 7
TIP: break 2 and continue 2 act on the outer loop when loops are nested.

REMEMBER

  • match is strict (===) and returns a value.
  • do...while always runs once; foreach is the best loop for arrays.
  • continue skips one iteration; break leaves the loop.
LESSON 7 OF 13

FUNCTIONS

A function is a named block of code you can reuse. It can take inputs (parameters) and give back a result with return.

Defining and calling

function greet(string $name, string $greeting = "Hello"): string {
    return "$greeting, $name!";
}
echo greet("Ana"), "\n";
echo greet("Ben", "Welcome");
OUTPUT
Hello, Ana!
Welcome, Ben!

Type declarations (string, int, ?int for "int or null") and return types make bugs easier to catch.

Named arguments and variadics

function damage(int $base, int $bonus = 0, bool $crit = false): int {
    return ($base + $bonus) * ($crit ? 2 : 1);
}
echo damage(10, crit: true), "\n";   // named argument skips $bonus

function total(int ...$nums): int {
    return array_sum($nums);
}
echo total(1, 2, 3);
OUTPUT
20
6

Variable scope

Variables outside a function are not visible inside it. Pass them in as parameters. A static variable keeps its value between calls.

$gold = 50;
function showGold() {
    return isset($gold) ? "visible" : "not visible";
}
echo showGold(), "\n";

function nextId() {
    static $id = 0;
    return ++$id;
}
nextId(); nextId();
echo nextId();
OUTPUT
not visible
3

Passing by reference

function heal(int &$hp, int $amount): void {
    $hp += $amount;
}
$hp = 40;
heal($hp, 30);
echo $hp;
OUTPUT
70

Anonymous functions and arrow functions

$multiplier = 3;
$triple = function ($n) use ($multiplier) {
    return $n * $multiplier;
};
$double = fn($n) => $n * 2;   // arrow functions capture outer variables automatically
echo $triple(5), " ", $double(5);
OUTPUT
15 10

Recursion

function factorial(int $n): int {
    return $n <= 1 ? 1 : $n * factorial($n - 1);
}
echo factorial(5);
OUTPUT
120
TIP: Add declare(strict_types=1); at the very top of a file to stop PHP from silently converting argument types.

REMEMBER

  • Use return to give a value back; echo only displays it.
  • Functions cannot see outside variables unless passed in (or captured with use / fn).
  • &$param lets a function change the caller's variable.

CLASSES & OBJECTS

Object-oriented programming groups data (properties) and behaviour (methods) together. A class is the blueprint; an object is one thing built from it.

A first class

class Hero {
    public string $name;
    private int $hp = 100;

    public function __construct(string $name) {
        $this->name = $name;
    }

    public function takeDamage(int $amount): void {
        $this->hp = max(0, $this->hp - $amount);
    }

    public function getHp(): int {
        return $this->hp;
    }
}

$h = new Hero("Ana");
$h->takeDamage(30);
echo $h->name, " has ", $h->getHp(), " HP";
OUTPUT
Ana has 70 HP

Visibility

  • public: usable from anywhere.
  • protected: usable inside the class and its child classes.
  • private: usable only inside the class that declares it.

Constructor property promotion (PHP 8)

class Item {
    public function __construct(
        public string $name,
        public int $price = 10,
    ) {}
}
$potion = new Item("Potion");
echo $potion->name, " costs ", $potion->price;
OUTPUT
Potion costs 10

Static members and constants

class Game {
    const VERSION = "1.0";
    public static int $players = 0;

    public static function join(): void {
        self::$players++;
    }
}
Game::join();
Game::join();
echo Game::VERSION, " ", Game::$players;
OUTPUT
1.0 2

Use -> for objects ($obj->method()) and :: for static members and constants (Class::CONST).

Objects are handles

class Box { public int $v = 1; }
$a = new Box();
$b = $a;         // same object
$c = clone $a;   // a copy
$b->v = 5;
echo $a->v, " ", $c->v;
OUTPUT
5 1

REMEMBER

  • new creates an object; $this is the current object.
  • Keep data private and expose it through methods.
  • Assigning an object does not copy it; use clone for a copy.
LESSON 9 OF 13

INHERITANCE, INTERFACES & TRAITS

These tools let classes share and reuse code.

Inheritance with extends

class Monster {
    public function __construct(protected string $name) {}
    public function attack(): string {
        return "{$this->name} attacks";
    }
}
class Boss extends Monster {
    public function attack(): string {
        return parent::attack() . " with fire!";
    }
}
echo (new Boss("Dragon"))->attack();
OUTPUT
Dragon attacks with fire!

Abstract classes

An abstract class cannot be created with new. Its abstract methods must be written by the child classes.

abstract class Shape {
    abstract public function area(): float;
    public function describe(): string {
        return static::class . " with area " . round($this->area(), 2);
    }
}
class Circle extends Shape {
    public function __construct(private float $r) {}
    public function area(): float { return M_PI * $this->r ** 2; }
}
echo (new Circle(2))->describe();
OUTPUT
Circle with area 12.57

Interfaces

An interface is a contract: a list of methods a class promises to have. A class can implement several interfaces.

interface Healable {
    public function heal(int $amount): void;
}
class Player implements Healable {
    public int $hp = 50;
    public function heal(int $amount): void { $this->hp += $amount; }
}
$p = new Player();
$p->heal(25);
echo $p->hp, " ";
var_dump($p instanceof Healable);
OUTPUT
75 bool(true)

Traits

A trait is a bundle of methods you can paste into any class with use. It solves "I need the same methods in unrelated classes".

trait Loggable {
    private array $log = [];
    public function log(string $msg): static {
        $this->log[] = $msg;
        return $this;
    }
    public function history(): string {
        return implode(", ", $this->log);
    }
}
class Quest { use Loggable; }
echo (new Quest)->log("start")->log("win")->history();
OUTPUT
start, win
TIP: Method priority: the class's own method beats a trait method, and a trait method beats an inherited one.

Late static binding

class Model {
    public static function create(): static { return new static(); }
}
class User extends Model {}
echo get_class(User::create());
OUTPUT
User
COMMON MISTAKE: PHP has single inheritance: a class can extends only one parent. Use interfaces and traits for the rest.

REMEMBER

  • extends = inherit from a class; implements = follow an interface; use = include a trait.
  • parent::method() calls the parent version of an overridden method.
  • static refers to the class that was actually called.
LESSON 10 OF 13

ERRORS & EXCEPTIONS

Exceptions let you stop when something goes wrong and handle the problem in one place.

try, catch, finally

function withdraw(int $balance, int $amount): int {
    if ($amount > $balance) {
        throw new InvalidArgumentException("Not enough gold");
    }
    return $balance - $amount;
}

try {
    echo withdraw(50, 80);
} catch (InvalidArgumentException $e) {
    echo "Error: ", $e->getMessage();
} finally {
    echo "\nfinally always runs";
}
OUTPUT
Error: Not enough gold
finally always runs

Catching several types

try {
    echo intdiv(1, 0);
} catch (DivisionByZeroError | TypeError $e) {
    echo get_class($e), ": ", $e->getMessage();
}
OUTPUT
DivisionByZeroError: Division by zero

Your own exceptions

class QuestFailed extends Exception {}

try {
    throw new QuestFailed("Boss escaped", 7);
} catch (Exception $e) {   // also catches subclasses
    echo get_class($e), " #", $e->getCode(), ": ", $e->getMessage();
}
OUTPUT
QuestFailed #7: Boss escaped

Error vs Exception

  • Exception: problems your code expects and throws on purpose.
  • Error: problems from PHP itself, e.g. TypeError, DivisionByZeroError, calling an undefined function.
  • Both implement Throwable, so catch (Throwable $e) catches everything.
TIP: During development turn on error_reporting(E_ALL) and display_errors. On a live site, log errors instead of showing them to visitors.

REMEMBER

  • throw raises an exception; catch handles it.
  • finally runs whether or not an exception happened.
  • Catch the most specific type you can.
LESSON 11 OF 13

FORMS, SESSIONS & SECURITY

PHP was built for the web. It can read form data, remember users between pages and talk to the browser with cookies.

Superglobals

  • $_GET: values from the URL, e.g. page.php?id=5.
  • $_POST: values sent by a form with method="post".
  • $_SESSION: data kept on the server for one visitor.
  • $_COOKIE: small values stored in the browser.
  • $_SERVER: request info, e.g. $_SERVER["REQUEST_METHOD"].

Handling a form

<form method="post" action="login.php">
    <input name="username">
    <input name="password" type="password">
    <button>Log in</button>
</form>
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $username = trim($_POST["username"] ?? "");
    if ($username === "") {
        echo "Username is required";
    }
}
TIP: Use POST for passwords and anything that changes data. GET puts values in the URL, where they end up in history and logs.

Validating input

var_dump(filter_var("ana@example.com", FILTER_VALIDATE_EMAIL));
var_dump(filter_var("42abc", FILTER_VALIDATE_INT));
var_dump(filter_var("18", FILTER_VALIDATE_INT));
OUTPUT
string(15) "ana@example.com"
bool(false)
int(18)

Escaping output (prevent XSS)

Never print user input straight into HTML. htmlspecialchars() turns special characters into safe entities.

$comment = "<script>alert(1)</script>";
echo htmlspecialchars($comment, ENT_QUOTES, "UTF-8");
OUTPUT
&lt;script&gt;alert(1)&lt;/script&gt;

Sessions

session_start();                 // call before any output
$_SESSION["user"] = "Ana";       // remember the user

// on another page:
session_start();
echo $_SESSION["user"] ?? "Guest";

// logging out:
session_unset();
session_destroy();

Cookies

setcookie("theme", "dark", time() + 86400 * 30, "/");  // 30 days
echo $_COOKIE["theme"] ?? "light";

Storing passwords

$hash = password_hash("secret123", PASSWORD_DEFAULT);
var_dump(password_verify("secret123", $hash));
var_dump(password_verify("wrong", $hash));
OUTPUT
bool(true)
bool(false)
COMMON MISTAKE: Never store plain-text passwords, and never use md5() for them. Always use password_hash() and password_verify().

REMEMBER

  • Validate input on the way in; escape it with htmlspecialchars() on the way out.
  • Call session_start() before using $_SESSION.
  • Hash passwords with password_hash().
LESSON 12 OF 13

DATABASES WITH PDO

PDO (PHP Data Objects) is the standard way to talk to databases such as MySQL, PostgreSQL and SQLite from PHP.

Connecting

$pdo = new PDO(
    "mysql:host=localhost;dbname=game;charset=utf8mb4",
    "db_user",
    "db_password",
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

Prepared statements

Put placeholders (? or :name) in the SQL and send the values separately with execute(). The values can never change the query, which blocks SQL injection.

$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE players (id INTEGER PRIMARY KEY, name TEXT, score INT)");

$insert = $pdo->prepare("INSERT INTO players (name, score) VALUES (:name, :score)");
$insert->execute(["name" => "Ana", "score" => 120]);
$insert->execute(["name" => "Ben", "score" => 90]);
echo "New id: ", $pdo->lastInsertId(), "\n";

$stmt = $pdo->prepare("SELECT name, score FROM players WHERE score > ? ORDER BY score DESC");
$stmt->execute([50]);
foreach ($stmt->fetchAll(PDO::FETCH_ASSOC) as $row) {
    echo $row["name"], ": ", $row["score"], "\n";
}
OUTPUT
New id: 2
Ana: 120
Ben: 90

Fetching results

  • fetch(): the next row (or false when there are no more).
  • fetchAll(): every row as an array.
  • fetchColumn(): a single value, e.g. from SELECT COUNT(*).
  • PDO::FETCH_ASSOC: rows keyed by column name.

Updating and deleting

$pdo = new PDO("sqlite::memory:");
$pdo->exec("CREATE TABLE items (name TEXT, qty INT)");
$pdo->exec("INSERT INTO items VALUES ('potion', 3), ('ether', 1)");
$stmt = $pdo->prepare("UPDATE items SET qty = qty - 1 WHERE name = ?");
$stmt->execute(["potion"]);
echo "Rows changed: ", $stmt->rowCount(), "\n";
echo $pdo->query("SELECT SUM(qty) FROM items")->fetchColumn();
OUTPUT
Rows changed: 1
3
COMMON MISTAKE: Never build SQL by joining user input: "... WHERE name = '$name'" lets an attacker rewrite your query. Always use placeholders.

REMEMBER

  • Create a PDO object to connect; turn on exception mode.
  • prepare() + execute([...]) for every query that uses outside data.
  • Pick a fetch method: fetch, fetchAll or fetchColumn.

MODERN PHP 8 FEATURES

PHP 8 added many features that make code shorter and safer. Here are the ones you will see most.

Nullsafe operator ?->

$user = null;
echo $user?->profile?->email ?? "no email";
OUTPUT
no email

Enums (PHP 8.1)

enum Difficulty: string {
    case Easy = "easy";
    case Hard = "hard";

    public function points(): int {
        return match ($this) {
            Difficulty::Easy => 10,
            Difficulty::Hard => 50,
        };
    }
}
$d = Difficulty::from("hard");
echo $d->name, " = ", $d->points(), "\n";

Generators

A generator uses yield to hand back values one at a time, so it can loop over huge data without building the whole array in memory.

function countdown(int $from) {
    for ($i = $from; $i > 0; $i--) {
        yield $i;
    }
    return "Liftoff!";
}
$gen = countdown(3);
foreach ($gen as $n) {
    echo $n, " ";
}
echo $gen->getReturn();
OUTPUT
3 2 1 Liftoff!
